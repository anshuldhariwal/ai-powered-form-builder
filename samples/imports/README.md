# Import samples

Assignment `.docx` and `.xlsx` fixtures will be stored here when import behavior is implemented. Milestone 0 installs and verifies PHPWord and PhpSpreadsheet but does not include feature-specific binary fixtures.

Planned samples cover:

- internship application documents;
- employee onboarding documents;
- field-definition spreadsheets;
- plain header-row spreadsheets.

Only synthetic, non-sensitive fixture data belongs in this directory.
